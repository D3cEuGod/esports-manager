# 峡谷经理人 · 英雄联盟电竞经理

一个以 2026 赛季英雄联盟职业赛事为背景的网页版电竞经理游戏（粉丝向原创作品，界面与美术均为原创）。

## 怎么玩

直接用浏览器打开 `dist/index.html` 就能玩，不需要安装或联网。打开后：

1. 选一支 LPL 战队开始执教。
2. 打 LPL 三个赛段，争取先锋赛、MSI、EWC 和世界赛的资格。
3. 在“转会”页买人或换人，在“阵容”页安排首发。
4. 比赛前进入 BP：
   - 标准 20 步职业 BP，全程无畏征召。
   - 先手选择权：选阵营或选 BP 先后手，对手拿剩下那项。
5. 打完世界赛进入休赛期，处理续约和转会，然后开始下一个赛季。

存档自动保存在浏览器本地，也可以在“存档”页导出或导入。

## 第一版内容

- **BP 与比赛模拟**：比赛结果取决于选手能力、英雄熟练度、版本强势英雄、阵容搭配和克制（开团、消耗、后期、抓单、前期），以及蓝色方优势。
- **选手交易**：报价、交换、签自由球员、出售、解约、续约，有预算和薪资。AI 球队之间也会互相转会。
- **赛季日程**：LPL 第一、二、三赛段 → 全球先锋赛 → MSI → EWC → LPL 世界赛资格赛 → 全球总决赛 → 休赛期。
- **选手池**：LPL、LCK、LEC、LCS、CBLOL、LCP 六个赛区，约 320 名 2026 赛季选手（见 `data/`）。

赛制细节写在游戏的“规则”页：✅ 表示已核实，⚠️ 表示推测或简化。

## 开发

```
src/            源码（engine.js 是规则和模拟，ui.js 是界面，champs.js 是英雄池，style.css 是样式）
data/*.json     各赛区选手名单，可以直接改
build.sh        把 data 和 src 合成单文件 dist/index.html
```

改完数据或代码后运行 `./build.sh` 重新生成。需要 Python 3。

## 数据说明

- 名单整理自公开资料：LCK、LPL、LEC、LCS 比较可靠，LCP 和 CBLOL 可信度偏低。
- 能力值、潜力、身价都是游戏估算，部分选手的年龄是随机生成的。
- “虚构新秀”是游戏生成的原创角色。
