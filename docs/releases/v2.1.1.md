### ✨ 本版本更新内容（相对 v2.1.0）

**🏆 新增：夺冠庆祝**
- 拿下冠军时播放全屏庆祝：奖杯、光芒、烟花与彩带，配合合成号角和礼炮音效（可静音），手机上会振动。
- 按赛事分别统计队史冠军数；世界赛冠军使用最高规格的庆祝效果。

**💰 修复：转会报价输入回溯**
- 输入转会费、切换交换选手时只刷新评估文字，不再整页重绘，数字不会再被“吃掉”或跳回。
- 后台刷新界面时会保住正在输入的输入框焦点和光标位置。

**🗺️ 修复：观战小地图显示不全**
- 桌面端小地图按可用区域的短边取正方形，不再被底部控制条压住。
- 贴近地图上沿的英雄名字改为显示在头像下方，不再被裁掉。

**📐 修复：页面比例与自适应**
- BP、赛前、赛后三栏锁定在一屏内各自滚动，确认 / 下一局按钮固定在底部。
- 窄屏优先显示中间操作区，BP 确认按钮吸底；手机比赛顶栏改为两行显示。
- 宽表格在窄屏可横向滚动；弹窗按钮吸底，并适配手机浏览器地址栏高度变化。

**🔧 其他**
- GitHub Pages 在线版部署流程修复（PWA 在线版可正常更新）。
- 发布流程改为从 `docs/releases/` 读取每个版本各自的更新说明。
