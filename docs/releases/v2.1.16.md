### 下载与更新

- 修复 Windows / macOS 客户端点「下载最新版本」没有反应的问题。现在游戏里的外部链接都会用系统浏览器打开，下载按钮会直接下载对应平台的安装包。
- Windows 安装版（Setup）和 macOS 支持游戏内一键更新：发现新版本后点「一键更新」，自动下载、校验签名、安装并重启。本次需要手动下载安装一次，之后的版本都能在游戏内更新。
- Windows 绿色便携版不能自我替换，点按钮会直接下载新版 Portable.exe。
- 在线网页 / PWA：按钮改为「刷新到新版本」。
- 版本检测以 GitHub 最新正式发布为准，不会在安装包还没编译完时提前提示更新。

### 安卓

- 从本版起使用固定签名，以后的新版 APK 可以直接覆盖安装。**本次需要先卸载旧版再安装**，卸载前请先导出存档或完成云同步。

### 云同步

- 已定位「云端存档接口不可用」的原因：云端数据库未对登录用户授权。修复需要在服务端执行一次 SQL，执行后无需更新客户端即可恢复。
